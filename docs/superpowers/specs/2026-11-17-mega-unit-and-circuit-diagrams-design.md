# Design — เพิ่มหน่วย MΩ และภาพวงจรทั้ง 3 แบบ (Lab 03 ต่อยอด)

## Intent / ทำไม
ผู้ใช้ต้องการกรอกความต้านทานเป็น **เมกะโอห์ม (MΩ)** ได้โดยตรง แทนการพิมพ์ `1000 kΩ` สำหรับ RB และต้องการ **ภาพวงจรทั้ง 3 แบบ** (Voltage Divider / Fixed Bias / Emitter Bias) เพื่อแนบกับการส่งงาน Lab 03

## Goals
- dropdown หน่วยของ R1, R2, RB, RC, RE มี `MΩ` เพิ่มจาก `Ω` / `kΩ`
- `app.py` แปลงหน่วยใหม่ `mohm` → `× 1,000,000 Ω`
- คำว่า `mega` ยังต้องเป็นหน่วยผิดอยู่ (test เดิม `test_unknown_unit_shows_error` ใช้ `mega`)
- ผลคำนวณ ค่า default และ key ของผลลัพธ์ไม่เปลี่ยน — A1–A5 ยังเหมือนเดิม
- มีภาพวงจร 3 แบบใน repo อ่านค่าในภาพชัดเจน

## Non-goals / Anti-goals
- ไม่เปลี่ยนสมการใน `dc_bias.py` หรือ registry
- ไม่เปลี่ยน `units.py` (ฝั่งแสดงผลโชว์ MΩ อยู่แล้ว)
- ไม่เปลี่ยนค่า default ของฟอร์ม (`rb = 1000 kΩ` ยังอยู่)
- ไม่ใช้ภาพ AI ที่ตัวอักษร/ตัวเลขอาจเพี้ยน หรือบริการวาดวงจรภายนอก

## Constraints
- AGENTS.md: `app.py` แค่ parse + แปลงหน่วย, `dc_bias.py` บริสุทธิ์, template แสดงอย่างเดียว
- ต้องผ่าน `python -m unittest discover -s tests` (ตอนนี้ 54 tests)
- โปรเจกต์ push ไปแล้ว → งานนี้ต้อง commit ใหม่ + push อีกครั้ง + **SHA เปลี่ยน** แล้วแจ้งผู้ใช้ให้ไปอัปเดต Moodle

## Approaches

### หน่วย MΩ
- **A — เพิ่ม `mohm` ให้ทุกช่อง resistor (เลือก):** แก้ `_to_ohms()` ให้รับ `mohm` และเติม `<option value="mohm">MΩ</option>` ทั้ง 5 dropdown; ใช้โค้ด path เดิม ไม่มี state ใหม่; ตรงกับความคาดหวังว่าทุกตัวต้านทานกรอกหน่วยเดียวกันได้
- **B — เฉพาะช่อง RB:** แก้น้อยกว่า แต่ผู้ใช้สับสนได้ว่า R1/RC/RE ทำไมไม่มี MΩ
- **C — เปลี่ยน default เป็น `1 MΩ`:** แก้ default form ให้ใช้หน่วยใหม่เลย; ไม่จำเป็นและทำให้ A1 (Divider) กับ A2 (Fixed) สับสน

### ภาพวงจร
- **A — เขียน SVG ด้วยมือ + ส่งออก PNG (เลือก):** วาดสัญลักษณ์ resistor/transistor/แหล่งจ่ายเอง ใส่ label และค่าอ้างอิงได้ตรงทุกตัวเลข; เก็บ `.svg` ต้นฉบับและ `.png` สำหรับแนบใบงาน; ใช้ browser screenshot เป็นตัวแปลง ไม่พึ่งบริการภายนอก
- **B — สร้างภาพด้วยโมเดลภาพ:** เร็ว แต่ตัวอักษร `VCC`, `RB 1 MΩ` มักเพี้ยน ใช้แนบรายงานไม่ได้
- **C — screenshot จากเว็บจำลองวงจรภายนอก:** ต้องเข้าสู่ระบบ/อินเทอร์เน็ต และควบคุม style ไม่ได้

## Decision
เลือก **A** ทั้งสองข้อ: เพิ่ม `mohm` ครบทุกช่อง และวาดภาพ SVG เองแล้ว export เป็น PNG

## Parts of the how (ตัดสินแล้ว)
- `app.py`: `_to_ohms()` เพิ่ม `if unit == "mohm": return float(raw) * 1_000_000.0`
- `templates/index.html`: เพิ่ม option `MΩ` ต่อจาก `kΩ` ในทั้ง 5 dropdown
- `units.py`, `dc_bias.py`, `DEFAULTS` ไม่แตะ
- tests: เพิ่ม test แปลง `mohm` ตรง `_to_ohms`, test POST ด้วย `rb_unit="mohm", rb="1"` ต้องได้ A2 (`1.13 mA`, `9.51 V`), เช็กว่า dropdown มี `value="mohm"` ครบ 5 แห่ง
- ภาพ: เก็บที่ `docs/images/voltage-divider.svg`, `fixed-bias.svg`, `emitter-bias.svg` + `.png` ที่สอดคล้องกัน; แต่ละภาพมีชื่อวงจร, VCC/RC/β/VBE, R1/R2 หรือ RB/RE ตามโหมด, จุดกราวด์, และค่าอ้างอิง A1–A5
- เอกสาร: อัปเดต README (หน่วย MΩ + ลิงก์ภาพ) และ `docs/validation.md` ถ้าจำเป็น
